# ROMEOREX IS LIVE — Instagram OS

Independent Instagram creator command center for **@romeorexislive**.

**Brand identity**
- Display name: ROMEOREX IS LIVE
- Tagline: DOMINATE EVERY MATCH
- Content focus: BGMI, gaming, esports moments, creator technology

## Features
- Premium black / crimson / metallic-silver responsive command center
- Daily Instagram content desk and creator checklist
- Reels and caption package generator (hook, caption, hashtags, cover direction)
- Content calendar with review / approval statuses
- Manual Instagram Insights growth tracker
- Local browser storage, JSON backup export and restore

## Run / deploy
Static website. Open `index.html` or import this repository into Vercel.
- Framework preset: Other
- Build command: leave blank
- Output directory: `.`
- Environment variables: none

## Important boundaries
This repository is Instagram-only. It does not contain or connect to the user's YouTube project, channel data, or YouTube publishing workflow.
This static version does not run scheduled background research, verify live BGMI news/redeem codes, connect to Instagram Insights, or auto-publish. Verify updates from official sources and approve content before posting. Official integrations require Meta permissions and setup.

## Privacy
Drafts, calendar items, settings, daily brief, and metrics are stored in browser local storage on the device/browser used. Use Export backup before clearing browser data.
